## Why this is an adaptation

The Fluent UI skill is tied to Nx, Yarn, Storybook packages, and Fluent V9's
monorepo layout, so it was not copied. This Meibook-native skill keeps the useful
browser-evidence workflow while using React/Vite, FastAPI/SSE, Report Agent,
responsive/dark-mode checks, and repository safety rules.

No Fluent UI script or command was vendored into this directory.
